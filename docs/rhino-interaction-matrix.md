# Rhino 8 behavior → bounded GreenLens workspace

Official McNeel documentation is used for behavior only. All implementation and visual assets are original GreenLens work. No Rhino installation or proprietary format support is required. This table is a contract; verification outcomes are recorded separately.

| Behavior | GreenLens behavior | Official reference | Deliberate limit | Acceptance |
|---|---|---|---|---|
| Workspace and command area | Menus, compact tools, command prompt/history, right panels and coordinate/status strip around the viewport | [Rhino window](https://docs.mcneel.com/rhino/8/help/en-us/user_interface/rhino_window.htm) | Fixed bounded tool vocabulary; no ornamental CAD controls | Native 1366×768/1920×1080 layout/scaling |
| View activation/maximize | Four named views; title click activates, double-click maximizes/restores | [Rhino window](https://docs.mcneel.com/rhino/8/help/en-us/user_interface/rhino_window.htm) | Four fixed view identities, no arbitrary viewport creation | Demonstrations 1–2; camera persistence tests |
| Pan/orbit/zoom | RMB orbit Perspective; Shift+RMB pan; orthographic RMB pan; wheel zoom | [Pan](https://docs.mcneel.com/rhino/8/help/en-us/commands/pan.htm), [mouse functions](https://docs.mcneel.com/rhino/8/help/en-us/popup_actions/mouse_buttons.htm) | Orthographic projections stay locked; no orthographic tumble | Camera and native pointer tests |
| Selection | Click/hover, Shift-add/Ctrl-remove, explicit Replace/Add/Remove modes with visible count/names, L→R containment/R→L crossing, Escape, overlap chooser | [Selection commands and object-selection basics](https://docs.mcneel.com/rhino/8/help/en-us/commands/selection_commands.htm) | Semantic parametric entities, never triangles as CAD objects; persistent mode buttons are a GreenLens discoverability aid | Demonstration 3, production pointer-listener and projected-boundary tests |
| Constrained manipulator | Supported axis/plane handles and numeric entry for Move/Resize/Rotate | [Gumball](https://docs.mcneel.com/rhino/8/help/en-us/commands/gumball.htm) | No copy/extrude/free transforms; unsupported degrees explained | Demonstrations 4, 6–8 and transaction tests |
| Grid snapping | Visible construction grid; snap accepted supported coordinates to a declared increment | [Snap](https://docs.mcneel.com/rhino/8/help/en-us/commands/snap.htm) | Separate from scientific sensor grid | Demonstration 5; coordinate assertions |
| Ortho | Constrain provisional planar movement to one supported axis | [Ortho](https://docs.mcneel.com/rhino/8/help/en-us/commands/ortho.htm) | Axis constraints in model-local construction coordinates; no custom-angle tracking | Demonstration 5 and diagonal-drag tests |
| Object snaps | Endpoint/midpoint/center candidates, proximity tolerance, visible marker and coordinates | [Modeling aids](https://docs.mcneel.com/rhino/8/help/en-us/options/modeling_aids.htm) | Move grip on rectangular semantic geometry only; Resize/Rotate use grid/angular snapping and exact values; no curve intersection/tangent/perpendicular solving | Snap priority/tolerance tests and native edit |
| Layers/locks | Room, glazing, shading, context, sensors/results display groups; hide and edit-lock | [Layer](https://docs.mcneel.com/rhino/8/help/en-us/commands/layer.htm) | Fixed semantic membership; visibility never alters simulation scene | Demonstration 9; hash/scene invariance |
| Commands and numeric input | Case-insensitive registered commands, autocomplete, prompts, units, history and bounded repeat | [Rhino window](https://docs.mcneel.com/rhino/8/help/en-us/user_interface/rhino_window.htm) | No script evaluator, shell, aliases to arbitrary code or unlimited command language | Parser/action tests and native command runs |
| Document undo | One committed edit per history entry; exact restore, redo, invalid/Escape exclusion | [Undo](https://docs.mcneel.com/rhino/8/help/en-us/commands/undo.htm) | Scientific edits only; views/selection are separate | Demonstrations 6–8 and dirty/stale/history tests |
| Open/Save As | Native dialogs, guarded document replacement and full portable copy | [SaveAs](https://docs.mcneel.com/rhino/8/help/en-us/commands/saveas.htm) | GreenLens project directory/JSON, no 3DM/DWG | Demonstrations 10–12 and conflict/copy regressions |

GreenLens keeps east/north/up scientific coordinates and an explicit `[x,z,-y]` renderer transform. Top looks down world Z; Front looks from south toward north; Right looks from east toward west. The visible grid uses world XY/XZ/YZ planes with 1 m lines, while supported parameter snapping uses model-local 0.1 m increments. The coordinate strip reports world ENU; scene objects are transformed by the room's supported vertical-axis rotation. Camera/display edits do not affect input hashes or run validity.
