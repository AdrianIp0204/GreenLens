## Ownership and integration

Root owns contracts/plan, frontend document controller/actions/commands/Properties/workspace composition and final integration/release. Backend owner handles persistence/recovery/export limits, Rust validation interfaces and native dialog/service commands. Viewport owner handles renderer lifetimes, cameras, semantic interaction, constrained previews and snapping math. Toolchain owner handles build provenance/version manifests/locks/CI/packaging, then native verification. Shared interfaces are agreed before integration; no competing edits to owned files. Retain one application service and a single accepted-document transaction path.
