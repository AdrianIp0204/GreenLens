## cDA and transport interpretation

A cDA is 79.46794327068856% for shipping and 80.31653300760063% for reference, a difference of −0.8485897369120607 pp. The 83 DA-crossing hours contribute only −0.042136185422540495 pp to cDA. The 2,151 hours below 300 lx in both runs contribute −0.8064535514895085 pp; the 1,416 hours above threshold in both contribute zero. Thus the DA discontinuity and the smoother cDA result are arithmetically consistent. No metric arithmetic or serialization bug was found in these inputs.

The sensor is at `(2.4375, 5.291666666666666, 0.8)` m. A has no overhang or surrounding obstruction. B differs scientifically only by the documented 0.60 m overhang; shipping and reference use identical geometry for each alternative. All four runs retain the same 4,411 generated solar source directions and radiances.

An independent conservative direction bound excludes direct sunlight through the aperture at **all 83 A crossings**. Using the effective sensor height of 0.8001 m, the largest possible altitude to the window head is 16.82234044°. At 79 crossings the entire solar disc is above that limit. At the other four, conservative full-cap ray/plane intersection bounds miss the window rectangle. This geometric exclusion does not rely on the production aperture-culling implementation. The 1,024-versus-4,096 finite direct-disc quadrature therefore cannot directly cause these particular crossing differences.

The evidence is consistent with differences in diffuse/ground transport and/or reflected solar transport. It does **not** isolate coefficient sampling as the cause: shipping/reference jointly change MF2/MF4 sky basis, bounce depth 8/9, full/direct coefficient samples 131,072/262,144, and direct-disc samples 1,024/4,096. The retained combined arrays do not separate these components, and the reference is not assumed to be ground truth. The 2-point limit permits at most 73 net hourly classification differences for this schedule; the observed 83 exceeds it by 10. No hours, sensors, occupancy weights or tolerances were removed or changed.

## Reproduction and limits

The repository includes [scripts/inspect-annual-da.py](../scripts/inspect-annual-da.py), copied from the original standard-library inspector with explicit input/output arguments. Python 3.10 or later is needed only for this independent analysis; GreenLens does not require Python. Supply the retained directory containing `convergence.json` and `shipping-A.zip`, `reference-A.zip`, `shipping-B.zip`, `reference-B.zip`. The large source exports remain local evidence; their exact hashes are recorded in the sealed diagnostic.

```powershell
$inputDirectory = Join-Path $env:LOCALAPPDATA 'GreenLens/verification/v0.3 corrected annual candidate b0b46d98 空間/convergence'
$outputFile = Join-Path $env:LOCALAPPDATA 'GreenLens/verification/annual-da-diagnostic/repeated-inspection.json'
python scripts/inspect-annual-da.py --convergence-dir $inputDirectory --output $outputFile
```

The output parent directory must exist, and the output file must be new. Run from the repository root without Python's `-O` option; the script explicitly rejects disabled integrity assertions. The optional `--check-record` argument selects a preserved diagnostic JSON; by default it uses this repository's sealed record. This is a bounded reproduction of the recorded 24-sensor fixture, its geometry and schedule, not a general-purpose evidence importer.

The script verifies the four archives, recomputes metrics from sealed raw channels, enumerates **every** occupied DA disagreement, and compares all **40 numerical, identity, scope and interpretation fields** with the published record before writing. Only four repeat-specific metadata fields are excluded: generation timestamp, input location, script digest and script location. The public record preserves the original local script's digest and the original diagnostic bytes; a repeated inspection records the repository script's own digest. Neither the original failed result nor its timestamp is replaced. The script also reproduces the publication's compact geometry fields and season summary.

Verified with Python 3.14 on the retained exports: all 40 compared fields matched, including all 480 metrics and all 83 failed A crossings. A deliberately altered DA value in a temporary comparison record was rejected before output creation; an existing output file and execution with disabled assertions were also rejected. The unchanged two-percentage-point acceptance failure remains explicit.
