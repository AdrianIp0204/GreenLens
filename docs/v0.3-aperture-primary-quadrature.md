# Direct-aperture primary quadrature investigation

The fixed 128×128 cosine hemisphere midpoint grid failed **28 of 96** black-room direct-aperture checks on 11 October 2026. At the same 16,384-primary count, the separately predeclared Hammersley rule passed all 96. This identifies a deterministic sampling error in the midpoint grid for these aperture boundaries. It does not qualify either rule for reflected transport, a Perez sky, solar treatment, annual metrics or a production profile.

The [complete evidence](evidence/v0.3-engine/aperture-primary-quadrature.json) retains both declarations, all 576 comparisons, every failed observation, each independently integrated reference, raw source-record hashes and exact input identities. Original local records remain separate and immutable. The public JSON embeds parsed records using LF formatting; its source hashes identify the retained original bytes, including the original midpoint report's CRLF formatting.

## Fixed fixture and declarations

Both alternatives use the actual 24 ordered sensors and synthetic model snapshots from the controlled-reference investigation. The room is 4×6×3 m, with its 1.8×1.5 m south opening at x=1.1–2.9 m, y=0, z=0.9–2.4 m. Sensors use the existing 4×6 equal-area grid at z=0.8 m. Both integrators use the inspected research generator's effective origin, sensor position plus 0.0001 m upward. Alternative B retains the 0.6 m horizontal overhang at z=2.4 m and x=1.1–2.9 m; A has none.

For this diagnostic only, the opening is unglazed, every opaque surface including B's overhang is black, and lower-ground luminance is zero. There are no interreflections. The original model snapshots retain their original material values; the declaration explicitly records these fixture overrides.

The two skies have exterior horizontal illuminance `E_out=10,000 lx`:

- Uniform upper hemisphere: `L=E_out/pi`.
- Prescribed CIE overcast distribution: `L=3*E_out*(1+2*omega_z)/(7*pi)`.

Before execution, the oracle orders were fixed at 16, 32 and 64, with each adjacent change required to be at most **0.1%**. Every quadrature estimate uses the unchanged diagnostic band **max(5 lx, 5% of reference)**. This is a limited application of the existing matched-hour error band, not a replacement annual acceptance requirement. No sample rotation, offset tuning, sample rejection or tolerance adjustment was made.

## Independent area integral

For a sensor `(sx,sy,sz)` and a point `(x,0,z)` on the opening, set `u=x-sx`, `d=z-sz`, `c²=sy²+d²` and `r²=u²+c²`. The upward sensor cosine is `d/r`, the absolute aperture-normal cosine is `sy/r`, and the solid-angle area factor is `1/r²`. Thus the integrand is `L*sy*d/r⁴`.

The horizontal integration uses exact antiderivatives:

```text
I2(u) = u/[2*c²*(u²+c²)] + atan(u/c)/(2*c³)
I5(u) = u*(3*c²+2*u²)/[3*c⁴*(u²+c²)^(3/2)]
uniform strip = E_out/pi * sy*d * delta(I2)
overcast strip = 3*E_out/(7*pi) * sy * [d*delta(I2)+2*d²*delta(I5)]
```

For B, let `H=overhang_z-sz`, `P=overhang_projection`, and `ol,or` be its x edges. An aperture point is shadowed only when `d` lies between `H*sy/(sy+P)` and `H`. Its blocked x interval is `[sx+(ol-sx)*d/H, sx+(or-sx)*d/H]`, clipped to the aperture. The oracle subtracts that strip exactly. Vertical Gauss–Legendre integration is split at the shadow onset and every projected-edge clipping transition, so no quadrature cell straddles an unhandled discontinuity.

This oracle does not call the hemisphere direction generator or its ray intersection function. Twelve pure checks cover polynomial quadrature and derivatives of the antiderivatives. Independent source review confirmed the integral, normalization and projected-overhang geometry. The largest observed adjacent-order oracle change was **2.78289e-14 relative**, comfortably below the predeclared 0.1% bound.

## Results

Each row below covers A/B × 24 sensors × two skies, or 96 comparisons. Maximum absolute and relative errors may occur at different sensors.

| Rule | Primaries per sensor | Failed / 96 | Maximum absolute error | Maximum relative error |
|---|---:|---:|---:|---:|
| Midpoint 128×128 | 16,384 | 28 | 18.216613 lx | 10.303178% |
| Midpoint 256×256 | 65,536 | 0 | 10.675826 lx | 4.955367% |
| Midpoint 512×512 | 262,144 | 0 | 5.638399 lx | 1.656133% |
| Hammersley | 16,384 | 0 | 2.327043 lx | 2.746308% |
| Hammersley | 65,536 | 0 | 1.064172 lx | 0.704128% |
| Hammersley | 262,144 | 0 | 0.416191 lx | 0.281132% |

The midpoint rule uses `radius=sqrt((radial+0.5)/side)`, `phi=2*pi*(azimuth+0.5)/side` and `z=sqrt(1-radius²)`, matching the inspected [research generator](../scripts/annual-paired-grid.cs). The bounded 512×512 case extends that same formula for this diagnostic; it is not an accepted setting of the inspected generator.

The 128×128 failures divide into A uniform 6, A overcast 6, B uniform 8 and B overcast 8. The largest relative error is B's `s000013` under uniform sky: **95.825195 lx** versus **86.874374 lx**, an error of **8.950821 lx** against a **5 lx** allowance. The 256×256 maximum relative error is close to the 5% band. Larger fixed grids reduce the overall error here, but individual sensor errors need not improve monotonically because the grids are not nested.

The follow-up Hammersley rule was fixed before its run at `N=16,384,65,536,262,144`, using:

```text
i = 0 ... N-1
radius = sqrt((i+0.5)/N)
phi = 2*pi*radical_inverse_base2(i)
z = sqrt(1-radius²)
cosine-weighted primary weight = pi/N
```

It uses no rotation or scrambling and the same sequence at every sensor. The base-2 radical inverse starts `0, 1/2, 1/4, 3/4, 1/8, 5/8, 3/8, 7/8`. The Hammersley inspector reads the previously sealed, converged oracle and imports only the repository-owned geometry helper after checking its source identity. It never executes code from the retained evidence directory.

At 16,384 primaries, the mean absolute error over these 96 cases falls from **6.637464 lx** for the midpoint grid to **0.578853 lx** for Hammersley. This supports a separately declared investigation of a coupled Hammersley primary stream. It does not by itself authorize a production profile change or establish reflected-light accuracy. No candidate was compared with an unqualified annual reference in these checks, and the contribution of this error to earlier annual discrepancies has not been quantified.

## Reproduction

Python 3.14.3 with only its standard library was used for this optional research; the GreenLens runtime does not require Python. These commands invoke no simulation engine and leave production settings unchanged. `-B` prevents source-directory bytecode caches. The checked-in [input snapshots](evidence/v0.3-engine/aperture-primary-inputs/) retain exactly the original model and sensor bytes used here.

```powershell
$inputs = './docs/evidence/v0.3-engine/aperture-primary-inputs'
$midpoint = Join-Path $env:LOCALAPPDATA ('GreenLens/verification/aperture-midpoint-' + [guid]::NewGuid())
python -B ./scripts/annual-aperture-quadrature.py --a-model "$inputs/A-model.json" --b-model "$inputs/B-model.json" --sensors "$inputs/sensors.pts" --generator ./scripts/annual-paired-grid.cs --output $midpoint
$hammersley = Join-Path $env:LOCALAPPDATA ('GreenLens/verification/aperture-hammersley-' + [guid]::NewGuid())
python -B ./scripts/annual-aperture-hammersley.py --baseline $midpoint --output $hammersley
```

Both inspectors write declarations before numerical execution, preserve all comparisons and produce checksum files. A diagnostic band failure remains in the result rather than erasing the evidence. The Hammersley run requires the same repository helper identity as its baseline. The study is limited to fixed unglazed geometry, black opaque surfaces and the two stated skies; native engine transport, glazing, nonuniform weather skies, reflected solar, annual convergence and complete release acceptance remain separate.
