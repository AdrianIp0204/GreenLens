Every value and UDI partition met the unchanged **1e-9 percentage-point** tolerance. Maximum observed differences were **1.42109e-14 percentage points** for both arithmetic and partition sums.

It does not import GreenLens calculation code. Independent review added explicit finite/range guards on actual CLI percentages; eight malformed values were rejected, three valid boundaries accepted, and the complete CLI verification passed again. The original finite-valued observation remains retained separately.

## Reproduction

Use the candidate04 distributed CLI and its copied three-run project. This fixture fixes interval 0 as zero-valued nighttime and interval 1908 as the retained daytime interval; it is not a general weather-interval selector. Python is required only for this optional independent verification script, not for GreenLens calculation or CLI metric derivation.

```powershell
$release = Join-Path $env:LOCALAPPDATA 'GreenLens/releases/0.3.0/native-candidate-04'
$cli = Join-Path $release 'GreenLens-CLI-0.3.0-windows-x64/greenlens.exe'
$project = Join-Path $env:LOCALAPPDATA 'GreenLens/native-verification/v0.3-candidate-04/Recovered portable copy 空間'
$output = Join-Path $env:LOCALAPPDATA ('GreenLens/verification/derived-metrics-' + [guid]::NewGuid())
python -B ./scripts/verify-derived-metrics.py --project $project --cli $cli --run 85876c9b-b031-4fe1-9c43-12c85420d299 --output $output
```

The script requires a new evidence directory and retains its declaration, settings, actual CLI stdout/stderr, independently computed values and checksums. The underlying command is `greenlens study metrics <project> <run-id> <metric-settings.json>`. There is no weekday inference, timezone conversion, resampling or mutation of stored run metrics. Desktop derived-metric editing and final-method scientific verification remain separate acceptance items.
