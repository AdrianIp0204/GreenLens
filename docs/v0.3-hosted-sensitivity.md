The plan's original declaration time and zero executed-variant count are a pre-dispatch snapshot, not a live status counter.

These data-only archives contain strict-reader baseline closure and notices, including synthetic derived octrees; they contain no engine binaries. Retained source and command arrays are evidence only. Only trusted checkout code executes. After execution a second strict read recomputes the selected variant. One passing variant cannot qualify all six or accept a production candidate.

Minimum-weight and depth comparisons remain max(0.1 lx, 1% of baseline) at every sensor. The original centroid and 4,096-ray finite correction arrays are reused byte for byte.
