# Paired Hammersley primary-ray investigation

This is a predeclared research experiment, not an accepted GreenLens calculation profile. It does not change the production adapter or reinterpret methods 2, 3 or 4. The regular midpoint-grid experiments and their failures remain retained.

The [independent black-aperture check](v0.3-aperture-primary-quadrature.md) found 28 failures among 96 cases for the regular 128 × 128 primary grid. A separately declared Hammersley rule passed those 96 direct-aperture cases at 16,384, 65,536 and 262,144 samples. That establishes limited aperture quadrature behavior. It does not establish reflected-light, Perez-sky, finite-sun or annual accuracy.

## Fixed experiment

Both alternatives use the same documented 24 sensors and these original interval indices: 1904, 1908, 1912, 4112, 4116, 4120, 6320, 6324, 6328, 8504, 8508 and 8512. Scene, model, weather, sensor, generated sky and source bytes are retained and hashed before execution. Both tuples use the identical MF2 sky; an eventual annual MF4 convergence test is separate.

| Parameter | Candidate | Higher sampling |
| --- | ---: | ---: |
| Explicit primary rays per sensor | 16,384 | 65,536 |
| Secondary ambient divisions (`-ad`) | 64 | 128 |
| Full radiance ambient bounces (`-ab`) | 7 | 8 |
| Paired direct ambient bounces | 0 | 0 |
| Finite-disc direct samples | 1,024 | 4,096 |
| Receiver scale | 100 | 100 |
| Ray depth (`-lr`) | -16 | -16 |
| Weight cutoff (`-lw`) | 1e-9 | 1e-9 |

For primary index `i = 0..N-1`, the horizontal radius is `sqrt((i+0.5)/N)`, azimuth is `2*pi*radical_inverse_base2(i)`, and upward component is `sqrt(1-radius*radius)`. There is no rotation or scramble. The same deterministic sequence is used at each sensor, whose effective origin is displaced upward by 0.0001 m. These are cosine-weighted radiance queries without `-I`; they replace the initial hemispherical bounce of the earlier irradiance formulation. They are not independent random observations.

Full and direct coefficient calls consume the same continuous sensor-major byte stream. `rcontrib -c N` averages the N radiance queries. Therefore assembly multiplies by `pi/100` once, without another division by N:

`E_RGB = pi/100 * [C_full * diffuse_ground + (C_full - C_direct) * solar_patches] + finite_direct_RGB`.

The diffuse/ground matrix retains exterior ground once. The direct subtraction applies only to the solar patch matrix. The finite-disc transmission octree has a unit receiver, separate from the coefficient receiver scaled to 100. RGB channels are retained separately before the authoritative lux conversion. Every negative coefficient difference or negative assembled reflected term is retained and fails the experiment; it is never clamped.

## Stream and lifecycle evidence

The typed C# producer writes ASCII/G17/LF records through a 64 KiB buffer, computes a SHA-256 receipt as bytes are written, and retains byte and ray counts. Each full/direct pair must have identical receipts. It creates no expanded primary-ray file and does not restart the process or sampling sequence between sensors. The producer accepts 1–256 upward sensors, but that is a tested input bound, not a claim that the maximum annual model has been benchmarked.

Nine generation/serialization checks cover the known base-2 sequence, all finite unit directions, cosine radial positions, sensor-major order, exact file/hash/count receipts, ASCII/LF bytes, cancellation and invalid inputs. Three synthetic native stream checks verify exact generated bytes through a real Windows child, a blocked producer timeout and an explicit generator failure. Their [compact evidence](evidence/v0.3-engine/hammersley-primary-stream.json) retains the actual tested source identities. The numerical coupling fixture additionally requires real Radiance uniform `pi*L`, black-room cancellation with retained glass, and nonnegative A/B coefficients before the larger candidate runs.

The research supervisor assigns the process to a kill-on-close Windows Job Object during `CreateProcess`, with an explicit inherited-handle list. One deadline covers the parent, descendants, producer, stdout and stderr. The [supervisor evidence](v0.3-paired-process-supervision.md) retains the earlier orphan-pipe failure and its repair. This is separate research infrastructure; production process semantics are unchanged.

The declared caps remain 7,200 seconds per process, 2 GiB observed runner-plus-job working set, 2 GiB scratch and 512 MiB per file. A failure preserves evidence and cannot count as completion. Concurrent engine work is capped and recorded; elapsed times are not isolated performance promises.

## Qualification remains pending

The controlled reference protocol must qualify every one of the 576 A/B sensor-hour values and its declared sensitivity cases before candidate agreement is accepted. The unchanged candidate tolerance is `max(5 lx, 5% of reference)` for every value. Full-year shipping/reference A/B metric convergence and native release acceptance remain required. Neither the aperture diagnostic nor a successful stream or coupling check replaces them.

Reproducible scripts:

- `scripts/test-annual-paired-primary-stream.ps1`: pure generation and serialization checks.
- `scripts/test-annual-hammersley-native-stream.ps1`: synthetic Windows stream and producer failure checks.
- `scripts/annual-hammersley-coupling.ps1`: bounded real-engine coupling fixtures, with `-Variant candidate` or `higher`.
- `scripts/annual-paired-hammersley.ps1`: fixed 24-sensor, 12-interval A/B experiment. `-PrepareOnly` seals inputs and settings without engine execution.

Each run requires a new output directory outside the source checkout. No retained package commands are executed.

## Observed coupling result

Both predeclared tuples completed all four real-engine coupling fixtures on 11 October 2026: uniform receiver, black opaque room retaining the glass, and the actual A/B geometry at `s000003` and `s000023`. All eight cases passed. Every full-minus-direct RGB coefficient was nonnegative without clamping; uniform and black-room pairs were exactly equal. The largest uniform deviation from πL was below 0.00002%. Full/direct primary byte, ray and SHA-256 receipts matched in each case. The [complete compact record](evidence/v0.3-engine/hammersley-coupling.json) preserves sensor totals, residual checks, exact settings, process records, input identities and raw-output hashes.

At 65,536 primaries per sensor, the A/B full calls took 366.652 and 381.743 seconds, with direct calls taking 2.106 and 2.284 seconds. These observations were made under concurrent verification load. They support this limited coupling/normalization check only. The 24-sensor, 12-interval Hammersley A candidate experiment has started with the unchanged declaration; full-grid accuracy, controlled-reference qualification and annual convergence remain pending.
