## Aperture reference

The fixture is a black plane at z=1 m with a 0.20 × 0.20 m opening, an upward sensor normal, and a 0.533° diameter solar disc at the zenith. Eleven fixed sensor positions include fully illuminated, half-disc, wholly blocked and six off-center boundary cases. Source radiance is deliberately non-gray: RGB `[1000000, 700000, 300000]`. Both 1,024 and 4,096 directions pass through the actual Rust ray generation, Radiance transmission and Rust integration. Every all-ray RGB value also agrees with its conservatively culled counterpart within the retained 1e-12 absolute bound.

The independent reference uses orthographic disc coordinates `(x,y)`, radius `s = sin(alpha)` and `z = sqrt(1-x²-y²)`. For a horizontal sensor, the cosine factor cancels the solid-angle Jacobian, so the irradiance integral is projected visible area. At the nearby right aperture edge the exact visibility condition is `sensor_x + H*x/z <= 0.1`, with `H = 1 - 0.0001` m. Solving gives `x <= c*sqrt((1-y²)/(1+c²))`, where `c = (0.1-sensor_x)/H`. Integrating the clipped horizontal disc width gives the reference without calling the production direction generator or aperture-intersection code. The other aperture boundaries do not intersect this fixed set of projected discs.

Midpoint integrations with 16,384 and 65,536 slices must converge within 0.1%; a zero reference requires exact zero. Each final sensor retains the unchanged `max(5 lx, 5% of reference)` limit. An additional RGB check uses `max(5/179, 5% of reference channel)`. The largest observed lux relative error was **0.511068%**, or 0.102214 of its allowed error. Maximum reference change was **1.94675e-7 relative**. Exact full-disc, half-disc and blocked limits are also checked independently.

## Equivalent glazing reference

A single neutral pane has normal transmittance 0.60 and refractive index 1.52. An opaque back plane prevents reflected receiver light from contaminating transmitted light. Fixed central incidence angles are 0°, 30° and 60°, each evaluated at both sample counts with the same non-gray source.

The reference independently combines Snell refraction, the two Fresnel polarization reflectances and Beer–Lambert attenuation with the incoherent internal-reflection sum. Internal normal attenuation is solved directly from the normal-transmittance quadratic, rather than reusing the production approximate conversion. Its angular law corresponds to the pinned engine's documented [equivalent thin-glass model](https://raw.githubusercontent.com/LBNL-ETA/Radiance/rad6R0P2/src/rt/glass.c); this verifies that simplified model rather than measured or coated glazing.

The reference integrates in orthographic polar coordinates with `dOmega = rho*d_rho*d_phi/sqrt(1-rho²)`, using 64×128 then 128×256 midpoint samples. It does not reuse production rays. Reference change must be at most 0.1%; actual RGB channels and lux must each agree within the prior glazing fixture's **1%** bound. Maximum observed relative lux error was **3.05956e-8**; reference change was **1.60232e-10**.

## Reproduction and CI scope

From the repository root, with the pinned native engine installed:

```powershell
. ./scripts/dev-env.ps1
$env:GREENLENS_FINITE_FIXTURE_ROOT = Join-Path $env:LOCALAPPDATA 'GreenLens/verification/finite-rust'
cargo test -p greenlens-radiance --lib annual::direct::tests --locked --offline -- --nocapture
cargo clippy -p greenlens-radiance --all-targets --locked --offline -- -D warnings
./scripts/annual-shadow-corrected.ps1 -OutputDirectory (Join-Path $env:LOCALAPPDATA ('GreenLens/verification/finite-edges-' + [guid]::NewGuid()))
```
