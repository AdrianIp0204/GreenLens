# v0.3 candidate: implemented, release acceptance incomplete

The climate workflow is implemented and has executed complete native Windows annual studies. It is **not an accepted v0.3 release**: the current method fails the frozen annual convergence requirement, the same-sky reference family is unqualified, and the carried physical Shift/Ctrl selection observation is unavailable. Successful replay establishes integration agreement, not physical accuracy. No failed threshold has been weakened.

## Available behavior

Rust services, the CLI and the installed Tauri workspace support strict local EPW import with retained source bytes and time policy; static, selected-hour and annual studies; hourly lux and sensor series; DA/cDA/UDI with editable occupancy and thresholds; compatible historical A/B comparison; cancellation; portable Save As; bounded evidence export and recognized-version replay. Scientific and metric identities are separate. Historical static evidence and climate methods 2–4 retain their existing inspection/replay identities.

The two baseline review defects are repaired: restoring a study/model finds its newest matching result, and edits reject changes to locked dependent geometry without adding history. See the [individual acceptance ledger](v0.3-implementation-plan.md), [native record](v0.3-native-verification.md) and [contracts](v0.3-contracts.md).

## Install, launch and inspect

The retained unsigned candidate09 distribution is under the per-user local application data directory at `GreenLens/releases/0.3.0/20261012-candidate09-b813b06`. It requires WebView2, the compatible Visual C++ v14 x64 runtime and separately installed pinned Radiance 6.0.2. A separate clean-machine installation has not been tested. Candidate08 remains available separately with its source-bound replay evidence.

```powershell
$release = Join-Path $env:LOCALAPPDATA 'GreenLens/releases/0.3.0/20261012-candidate09-b813b06'
& "$release/GreenLens_0.3.0_x64-setup.exe" /S
& "$env:LOCALAPPDATA/Programs/GreenLens/greenlens-desktop.exe"
$cli = Join-Path $release 'GreenLens-CLI-0.3.0-windows-x64/greenlens.exe'
& $cli doctor
& $cli weather inspect ./examples/weather/pvgis-hong-kong-tmy-2005-2023.epw --source-profile pvgis-tmy
```

The last command runs from the source checkout. Complete import, run, comparison, copy/export and replay commands are in [the usage guide](v0.3-usage.md). Original synthetic room inputs and the rights-reviewed PVGIS/ERA5 weather are in `examples`. Offline calculations do not require a downloader or cloud service. Fixed geometry, simplified neutral glazing, hourly typical weather and the investigation's numerical limits constrain interpretation; DA/UDI are not sDA, ASE, area percentages or certification.

Release completion still requires an accepted transport/reference method, passing full-year convergence, affected final-source CI/package/native rechecks and the missing physical modifier observation. Further engineering is needed for the numerical failures; repeating the existing runs, changing a display setting or approving a package cannot resolve them.
