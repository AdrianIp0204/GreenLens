## Operating-domain prerequisite blocked, 2026-10-14

The [source-bound observability review](evidence/v0.5/carrier-curve-observability.json), SHA-256 `b654528a8563e19fa66944246e30b1ec01094a5e68ddc13f343dd2bfa7dfb22b`, finds that requesting `Detailed` output cannot establish that every used coil-curve input stays within the published domain. [CurveManager](https://github.com/NREL/EnergyPlus/blob/4bd7a1f26fb749a83257855aba6760e26c8a3c8f/src/EnergyPlus/CurveManager.cc#L236) overwrites the same pre-clamp input cells on successive calls; the current adapter also shares each curve object across zones. [OutputProcessor](https://github.com/NREL/EnergyPlus/blob/4bd7a1f26fb749a83257855aba6760e26c8a3c8f/src/EnergyPlus/OutputProcessor.cc#L3398) samples the current cells after HVAC simulation. `Detailed` means the variable system timestep, not each curve evaluation or solver iteration, as the [official reporting documentation](https://energyplus.readthedocs.io/en/v26.2.0/guides/input-output-reference/1.5-group-simulation-parameters.html) specifies. The [single-speed DX dry-coil iteration](https://github.com/NREL/EnergyPlus/blob/4bd7a1f26fb749a83257855aba6760e26c8a3c8f/src/EnergyPlus/DXCoils.cc#L9684) may evaluate capacity repeatedly with changing temporary wet bulb before that sample.

The annual proposal therefore remains stopped before execution. An affirmative result would require a proven bound covering every actual argument, including internal iterates, or separately reviewed complete call-level observation with caller/activity attribution. Neither is established here; per-zone curve duplication alone would not close the internal-iteration gap. This review generated no engine output and observed no out-of-domain value. It identifies missing proof coverage, not an actual applicability failure of the unexecuted candidate. The analytical output-bound proof, exact selected inputs, original rejection, numerical criteria and historical outcomes remain unchanged. No substitute fit, schedule adjustment, instrumentation or annual run was attempted under this finite protocol; further call-level instrumentation would require a separately specified and audited method before adoption.
