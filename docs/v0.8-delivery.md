## Delivered workflow

Open an admitted GLB/reference project and select its genuine A/B run evidence. In Reference, choose **Review changes and carry forward**. The editable candidate is separate from the parent and generated proposal. Repair mappings or declarations using the existing structured forms, review the recomputed changes, provide the required rationale, then accept one atomic revision. Invalid or stale acceptance preserves the draft. Rationale capacity is measured in UTF-8 bytes, with a 2,048-byte limit.

Typed study/calendar provenance now uses a versioned contract: an unrelated COP change does not invalidate a declared unchanged calendar field. Ambiguous legacy declarations remain unresolved; old revision verification retains its original algorithm.

Reports displays the exact selected pair and scope before issuance. New renderer/2 products include complete bounded mapping/provenance artifacts, displayed/total counts and all-row exception summaries. Historical renderer/1 products remain supported and unchanged. A later revised scope cannot replace an issued scope. Missing sensitivity for the selected pair stays missing.

Use **Preview PDF** for a bounded offline view of checked issued bytes, **Save Copy** for the exact complete document at a new filename, or **Open copy folder**. External Open requests a Windows handoff and does not itself prove display. Inline preview is limited to 8 MiB, 160 pages and eight million canvas pixels per page. Original PDFs are not changed. Content-addressed viewer copies have a 128-product/256 MiB cap and are not automatically evicted while a viewer may require them.

Capacity panels show actual retained bytes and entries separately from incremental lower bounds and uncertain estimates. Final admission remains exact. When a complete study would exceed its bounds, preserve it and start a separately scoped document; history is never silently pruned. Save As and complete issued-project ZIP retain every required accepted revision, issue, normalized reference asset and run.
