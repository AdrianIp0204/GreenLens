# v0.8 workflow and delivery guide

This preview preserves earlier incomplete acceptance. It does not add qualified SKP support or change the thermal/physics scope. See the source checkout's v0.8 acceptance ledger for candidate-specific results.

## Run locally

Install the separately supplied unsigned `GreenLens_0.8.0_x64-setup.exe` for the current user. Launch GreenLens from Start. WebView2 is required. The matching CLI distribution contains `greenlens.exe` and offline notices. Engines and audited Typst/fonts remain separate; the existing Settings panel reports their readiness. A workstation installation is not a clean-machine test.

For a source checkout, PowerShell:

```powershell
. ./scripts/dev-env.ps1
cargo build -p greenlens-cli --release --locked
Set-Location apps/desktop
npm ci
npm run tauri -- build --ci
```

Build/cache paths remain outside synced source. Use a packaged application for native acceptance; a development server does not establish it.

## References and revisions

Import an admitted GLB through Reference. The hierarchy supports exact-occurrence selection, search, breadcrumbs and framing. Mesh reuse is identified from admitted glTF data; authoring tags and SketchUp component types are not inferred. Visibility does not affect analytical inclusion. SKP remains unavailable until the separate pinned-parser compatibility gates pass.

In scope history choose **Review changes and carry forward**. The proposed scope remains available separately from the editable candidate. Repair mappings with the existing target selectors, edit applicable assumptions and typed study/calendar fields, then refresh the review against the current context. The candidate input checklist shows the exact edited declarations that Rust will accept. To document an empty holiday calendar, choose **Explicit no-holidays calendar policy**, its design, literal `true`, source and rationale; this does not invent schedule overrides. Review required decisions and accept one new revision. Invalid, cancelled or stale review preserves the draft and accepted history. Rationale is limited to 2,048 UTF-8 bytes. Unresolved documentation remains visible and does not prohibit otherwise valid Unassessed calculations.

Retained report views restore in a fixed frame, preserving the accepted aspect ratio, extent and section when panels or windows resize. Letterboxing is intentional. Choose **Exit accepted frame** before ordinary navigation or capturing a different view; restoration never changes the accepted view or scientific inputs.

CLI equivalents (replace example names/IDs with selected retained identities):

Use command `--help` for exact accepted arguments. Inputs and report identities remain Rust-owned; no executable recipes are read from packages.

## Issued reports

Select the exact A/B pair and scope revision before issuing. New reports use renderer/3 with complete machine-readable mapping and review-decision data, displayed/total counts and exceptions from all rows. Documentation completeness and unresolved review decisions are separate disclosures; a sourced input is not automatically reviewed or approved. Old issued products and renderer/1 and /2 remain intact. Missing exact-pair sensitivity, coverage and qualification remain explicit.

**Preview PDF** renders verified retained bytes offline, within the displayed source/page/pixel/deadline bounds. **Save Copy** writes unchanged issued bytes to a new filename. **Open copy folder** reveals the content-keyed prepared copy. External Open requests a Windows handoff; it does not confirm display. If a viewer association fails, use inline preview or Save Copy. Cached viewer copies are limited to 128 files/256 MiB, reused only after digest verification and never automatically deleted. At capacity use Save Copy; manual maintenance must wait until external viewers are closed. Never remove immutable project members.

Capacity panels show actual retained size, known lower bounds and explicitly uncertain estimates. Starting permission is not a fit guarantee. Exact admission precedes publication; pending completed evidence is retained if publication fails. Preserve a full near-capacity study and create a separately scoped document rather than pruning issued history. Save As/export retain the complete admitted dependency closure.
