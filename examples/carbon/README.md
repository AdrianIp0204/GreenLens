# Explicit operational-emissions factors

The optional `clp-hong-kong-2025.json` records the published **0.34 kgCO2e/kWh** electricity-sold factor for CLP Power Hong Kong in 2025. It is distinct from the Group's generation-portfolio factor. Source: [CLP 2025 ESG Data Hub](https://sustainability.clpgroup.com/en/2025/esg-data-hub), reviewed 2026-10-13. The supplier/year/boundary must match the intended project; selecting this file does not establish accounting or certification eligibility. It is not the default factor for a fictional synthetic climate.
