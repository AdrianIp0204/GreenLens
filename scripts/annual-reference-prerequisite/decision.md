# One bounded qualification remedy — proposal, not execution authority

12 October 2026. This proposes one replacement reference estimator and one transport candidate. No native process, production change, new profile adoption or reference qualification has occurred. The rejected moment mapper remains rejected. Root must agree the decision, then review source/stream hashes and independent guards before execution.

## First decision: separate irradiance-primary allocation from the retained depth gap

The retained A4116 experiment makes the change from lr=-16 to -24 byte-identical at either ambient depth, while ab9 to ab10 reproduces the failed depth output. B8512 has not independently factorized lr. Permuting sensor order changes estimates but does not remove the depth discrepancy. Passing repeat and cross-seed comparisons therefore does not qualify the old estimator.

Pinned c1700d56 source establishes that aa=0 bypasses ambient interpolation. In this path hemisphere divisions depend on the incoming ray weight, material coefficient, ad and lw; they do not directly depend on ab. The ab limit terminates recursion. Parent ray number and primary sample index influence ambient samples, and additional recursion changes subsequent ray numbers/random state. Thus a lower deeper estimate is not a pathwise measurement of negative added light. V+ contribution filtering, float intermediate colors, roulette, and sampling allocation remain distinct possible mechanisms. Existing scale/lw controls weaken but do not eliminate cutoff explanations.

**Hypothesis R:** moving the first cosine hemisphere out of native I+ and keeping a moderate secondary ad will remove a consequential first-generation weight/allocation sensitivity. This does not assert the hypothesis is true, make sample paths depth-coupled, or establish a unique cause if it passes.

Only A4116 and B8512, all 24 original sensors, are in the first gate. Copy/revalidate the exact old scene, sky/source, weather/model/study, own centroid direct and finite4096 inputs/results from the reviewed baseline bundles. Keep the original actual MF2 sky plus original explicit source during this gate, so it changes the primary estimator without changing the solar representation. New source scale remains 100. Old original/deeper/permutation evidence is never replaced. The solar representation is known to have angular limitations, so passing this gate is **estimator eligibility, not a physically qualified reference family**.

For N=16384,32768,65536 separately, emit two complete identical full-domain Hammersley direction blocks in ONE uninterrupted process. Each block contains sensors s000001..s000024, each with i=0..N-1: r=sqrt((i+.5)/N), phi=2*pi*radical_inverse_base2(i), d=(r*cos(phi),r*sin(phi),sqrt(1-r*r)). Each origin is original point plus 0.0001 m along its original upward normal. No culling, new seed, rotation or ordering choice. The second block repeats the first block's primary bytes but retains native process sampling state. These two blocks are not statistically independent and are not called confidence intervals. The N ladders are NOT nested: no prefix of a larger N is used as a smaller-N estimate. Retain raw two-source RGB per primary; normalize each full-domain mean by pi/100 once.

Run each N at ab8 and ab9, fixed ad128/lr=-16/lw=1e-9. The I+ pseudo-surface consumes one ambient generation, hence these correspond to old I+ ab9/ab10; the equivalence is a depth-definition statement, not estimator equality. Exact arrays are in proposal.json. The highest fixed endpoint is N65536/ab9, never the most favorable output.

## Sole transport candidate: angularly masked finite rectangular emitter

If and only if the estimator gate passes, the one candidate for eligibility is a native rectangular area emitter with the **original constant solar RGB and original .533-degree cap**, masked by world z>0. No moment collapse, source brightness fit, angular clamping, discarded black interval or effective centroid. The mask is brightfunc `if(Dz,if(Dx*ux+Dy*uy+Dz*uz-cos(alpha),1,0),0)` with a declared measure-zero boundary convention. Pinned func.c exposes travel-toward-emitter ray direction as D; p_func/source.c apply it to emitted radiance, including after glass. No texture transform is permitted.

For every point p in a proven bounding sphere of radius B about O containing all modeled reflecting/glazing/obstruction geometry, use a plane normal toward the scene at O+R*u, R=2^20*max(B,1m). Define horizontal tangent e_h and vertical tangent e_v deterministically. Write q=O+R*u+R*x*e_h+R*y*e_v. Let T=tan(alpha), t=max(-T,-tan(altitude)). The upper-cap tangent-plane domain is x^2+y^2<=T^2, y>t. Its exact rectangle is y in[t,T], x in[-T,T] if t<=0, otherwise x in[-sqrt(T^2-t^2),sqrt(T^2-t^2)]. Expand each coordinate by B*(1+T)/R. This contains every p-to-original-cap intersection with the plane; the angular mask, not the rectangle boundary, selects emitted directions. Fully below/tangent zero-measure cases are explicit zeros; near-tangent arithmetic and f32 radiance/geometry validity must reject actionably if unrepresentable. R is an envelope/efficiency choice, not an assumption that parallax is zero. The mask defines the same radiance field at every enclosed point.

Use exactly ONE solar-hour plane per scene. This prevents artificial screen-to-screen occlusion; it is a new canonical source grouping of one original ordinal, not a claim of equivalence to old128/12/6+6 grouping. Preserve every original ordinal and black source in the annual map. Selected-hour work must use the identical source/sensor group and arguments that the full year would use. Diffuse/ground transport is a separate scene without the screen. Original finite4096 direct and pinned Perez/gendaymtx ground policy remain explicit and unchanged; angular screen light does not justify a cap-corrected ground claim.

Pinned four-vertex parallelograms are SFLAT, not SCIR. With ds=0 and dj=1 the source sampler chooses a uniform point in the rectangle and uses area*cos/distance^2 solid-angle weight. An earlier investigator statement that all rectangles were circular-warped was incorrect: bitwise | binds tighter than logical &&, so the remap requires SCIR. That incorrect interim inference is preserved here and is not used as evidence. Native source sampling is still stochastic; the mask can reject samples, and direct source paths/glass must be tested. This preserves angular support in principle but is not a numerical acceptance result.

The candidate solar tuple is paired external primaries N65536, full ab8/ad128 and the explicitly blackened-opaque ab0 control described above, lr=-16/lw1e-9/aa0/as0, ds0/dj1/u-/n1/V+, source scale100 with pi/100 applied exactly once after full-minus-black-control mean. Do not subtract ab0 of the actual reflective room. Use identical primary input bytes and source geometry/radiance for both passes. Retain no-clamp residual checks and original F4096; material fixtures must independently establish the control's direct-path meaning before any extension beyond these closed single-pane rooms. Diffuse uses the already declared higher MF2 no-I N65536/ad128/ab8 scale100 definition, but new complete candidate execution/evidence would still be required. This tuple is fixed now as a hypothesis, not chosen after new annual outputs. It does not define an accepted shipping/reference pair.

Before any room candidate or new angular reference, reuse all 42 original-cap angular/material cases in declaration348ac4fc (30 oriented/horizon +12 glass/knife), original aperture/overhang/obstruction fixtures, and original planar reflected-light expectations. Start with pure directional-field/envelope/Jacobian checks and unchanged original-cap oracles. A tiny native source-only fixture then has a predetermined repeat ladder4096,16384,65536 per sensor, two complete blocks each, and its own full/direct geometry. Require all exterior/planar/material source responses within the original1% band and original shadow/aperture band; no extra resolution after cap. **Exact scene literals, source/sensor files, fixture stage arrays/count and pure guard pins must be separately sealed and reviewed before this later gate; this proposal does not authorize its execution.** It is the same candidate, not permission to introduce another transport if it fails.

If those prerequisites pass, the SAME one reference estimator must be requalified with this angular source input, including the fixed minimal cases and then all24 prescribed reference cases, before candidate comparison. Old centroid reference totals are never relabeled angularly qualified. The reference numerical ladder/sensitivities remain exactly those above; source identity changes are explicit physical inputs. Expansion to 12x2 or annual work is not authorized by this initial decision. ## Alternatives rejected and stop rule

More old repeats, another favorable permutation, unrecordable time-seeded u+, progressively finer solar patches and the rejected moment mapper are not this remedy. A forked path-addressed Radiance sampler or independent transport solver is a possible specialist intervention if R fails; it is not a second recipe in this cycle. Native distant-source dj1 is not reused after its retained off-center failure. Multiple emitter planes in one scene are excluded because they can block each other. No practical full-year time claim is made: one-source grouping can mean4411 solar groups for the current weather and at most8760, and area sampling adds work at every reflective point. A later measured pilot must establish stage, memory, scratch, cancellation, file-count and export budgets before any annual authorization. Current256-sensor/7200s/512MiB/2GiB and5000-entry/256MiB export limits remain unchanged.

Stop the branch on any finite gate's unresolved numerical/resource failure. Preserve a minimal reproducer and precise unresolved mechanism; finish the independent qualification/presentation repair with an honest failed/unassessed status. No production Rust scaffold, no automatic full-year run, and no passing reference-family flag follow from this proposal.
